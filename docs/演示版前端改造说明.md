# 演示版前端改造说明（离线 Demo）

> 分支：`feat/demo-offline-frontend`　适用场景：比赛现场路演，**不依赖任何后端**。
> 代码改动位于 `frontend/`，本文档只做说明与验收记录。

## 1. 目标

1. 三端（老人 / 家属 / 村协）在**断网、无数据库**的环境下可完整演示。
2. 注册与登录**只做前端模拟**，不新增任何后端接口、API 请求、数据库操作或路由守卫。
3. 家属端 / 村协端**绝不暴露老人原始对话**，风险信息严格收敛到五个标准分类。
4. 老人端保持组员原版交互（点击式大麦克风按钮），仅移除顶部「一键呼叫家人」。

## 2. 改动清单

### 2.1 离线运行

| 文件 | 说明 |
| --- | --- |
| `src/config.ts` | `VITE_WORKER_API_URL` 默认值改为空字符串，三端默认走本地演示数据层 |
| `src/lib/api.ts` | 请求层在 base 为空时直接落到 `demoStore`，保留既有 `/api/...` 路径契约 |
| `src/lib/demoStore.ts` | 演示数据层：老人档案、预警、留言、处置记录、情绪趋势等 |

产物构建后 `index.html` 的 `<script type="module">` 可改为 `defer`，从而支持 `file://` 双击直接打开（`type="module"` 在本地文件协议下会被 CORS 拦截导致白屏）。

### 2.2 注册 / 登录：纯前端模拟

`src/pages/Login.tsx`、`src/pages/Register.tsx` 重写为三角色页签（老人 / 家属 / 村协管员），只做校验与前端跳转：

- 老人：姓名\*、密码\*、确认密码\*、手机号\*；（选填）年龄、性别、居住情况、所属村、住所位置、过往病史、紧急联系人；
- 家属：姓名\*、手机号\*、验证码、密码\*、确认密码\* —— 只做身份注册，**没有任何绑定老人入口**；
- 村协管员：家属字段 + 所属村镇（必填）；
- 验证码 60 秒倒计时、手机号 11 位校验、密码 ≥ 6 位且两次一致；
- 演示失败分支：`13800000001` ~ `13800000012` 为内置演示老人手机号，注册时提示"该手机号已注册"。

### 2.3 隐私：预警记录零原话 + 五分类结构化评估

**问题**：原预警卡片直接展示老人原话（如"对话中多次提到'活着没意思'"），存在隐私风险。

| 层面 | 处理 |
| --- | --- |
| 数据模型 | `AlertItem` 删除 `keyword`、`summary` 字段，改为 `category: RiskCategory`（只能是五个标准分类之一） |
| 评估逻辑 | 新增 `src/lib/assessment.ts`：按分类计数生成五维度评估 + 综合等级 |
| 展示组件 | 新增 `src/components/AlertRiskTag.tsx`：`风险类型：💗 情绪与自我价值 ｜ 状态：待处理` |
| 老人端上报 | `src/lib/risk.ts` 的 `RiskMatch` 只输出 `category`，`/api/risk-report` 只传 `category`，原话不出老人端 |
| 兜底收敛 | `asRiskCategory()` 把任何异常输入收敛到标准分类，绝不回退成原文 |

五分类（唯一可展示口径）：① 情绪与自我价值　② 家庭与社交适应　③ 健康与身体状态　④ 认知与安全风险　⑤ 经济与生活压力。

新增评估面板 `src/components/AssessmentPanel.tsx`，家属端整页展示、村协端点开老人详情弹层展示（同一口径）。

### 2.4 老人端

- 页面保持组员原版：顶栏 → 气泡对话流 → 底部 128px 大麦克风按钮（点一下说话、再点一下结束）+ `不方便说话？点这里打字` 兜底；
- **删除**顶部「📞 需要帮助？一键呼叫家人」按钮：HTML 块、`from-rose-500 to-orange-500` 等样式类名、`onClick` 与 `callOpen` 状态、`CallFamilyModal` 组件引用一并移除（`components/CallFamilyModal.tsx` 已删除）。

## 4. 本地运行

```bash
cd frontend
npm ci
npm run dev
```

接入真实后端时，在 `frontend/.env.local` 配置 `VITE_WORKER_API_URL` 即可，页面代码无需改动（见 `frontend/API-CONTRACT.md`）。
