# 乡音心伴｜前端开发说明

## 当前代码与部署

前端在 `frontend/`，采用 React、TypeScript、Vite、React Router 和 Tailwind，发布到 Cloudflare Pages。Pages 只托管静态文件；在线 API 使用 Cloudflare Worker `https://api.ccup.us.ci`。

- 页面：`frontend/src/pages`
- 组件：`frontend/src/components`
- API client：`frontend/src/lib/api.ts`
- Worker 登录会话：`frontend/src/lib/workerAuth.ts`
- 路由 UI 角色：`frontend/src/lib/session.ts`
- 构建变量：参考 `frontend/.env.worker.example`

生产构建必须配置 `VITE_WORKER_API_URL`，值为 Worker 根地址，不带 `/api`。API 请求由 Worker Bearer token 鉴权；Supabase 只由后端通过 Hyperdrive 连接，浏览器不需要 Supabase key。

本地开发：

    cd frontend
    cp .env.worker.example .env.local
    npm ci
    npm run dev

## 登录、注册和演示角色切换

- 手机号验证码为演示输入，不会发送短信；任意非空码由 Worker 接受。
- 注册时，前端先向 Worker `POST /api/register` 创建现有 schema 中的用户，再调用 `POST /api/demo-login` 获取 Bearer token，并读取 `GET /api/me` 初始化老人档案/家属绑定。
- 登录后 API client 对请求添加 `Authorization: Bearer <token>`。
- `VITE_DEMO_ROLE_SWITCH_ENABLED=true` 时显示角色切换按钮。三个 `VITE_DEMO_*_PHONE` 必须对应数据库里已注册且角色匹配的演示账号。
- `xy_role` 只控制页面路由，后端身份以 Worker 签名 token 为准。不要把真实用户或线上账号放入演示切换号码。

## 页面交互

- 老人端使用大字、高对比、大点击区域；录音状态、停止键和文字输入路径明确。
- ASR 低置信度时让老人确认文本；TTS 失败仍显示文字。
- 量表逐题呈现、可朗读、可返回/暂停；前端不下心理诊断结论。
- 家属和村协页面的数据由 Worker API 提供；路由守卫只是 UI 体验。
- 请求头变更需与 Flask-CORS 配置同步。
