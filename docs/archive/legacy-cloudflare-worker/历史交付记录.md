## 当前部署目标

- 前端已经单独部署，地址为 `https://ccup.us.ci`，Pages 备用域名为 `https://xiangyin.pages.dev`。
- 后端 API 地址保持 `https://api.ccup.us.ci`，本次不要求修改前端接口地址或重新部署 Pages。

## 部署入口

完整步骤见 [后端部署-Cloudflare-保姆级教程.md](1-给同学的后端包/乡音心伴-共享后端版/后端部署-Cloudflare-保姆级教程.md)。简要顺序：进入后端包目录 → `npx wrangler login` → `npx wrangler secret put AUTH_SECRET --name xiangyin-xinban-api` → `uv run pywrangler deploy` → 确认自定义域名 `api.ccup.us.ci` 仍绑定到这个 Worker。
