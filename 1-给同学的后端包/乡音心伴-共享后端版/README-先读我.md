## 三、60 秒跑起来

```bash
# 1. 装依赖（连云库这份）
pip install -r requirements-postgres.txt

# 2. 复制配置并填写
copy .env.example .env
#    → 把 DB_PASSWORD 换成真实密码（找我要），DB_MODE 保持 postgres

# 3. 启动
python app.py
#    或者直接双击：启动-共享数据库模式.bat

# 4. 浏览器打开
#    http://localhost:5000
```

**验证连对了库**：控制台应打印

```
[DB] 当前数据库模式: PostgreSQL（aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres）
```

如果打印的是 `SQLite`，说明你在写本地文件库，**数据不会进共享云库**（详见注意事项文档第一节）。

## 四、一张图看懂两个后端怎么共存

```
        ┌─────────────────────────┐
        │   前端（React 构建产物）  │
        └────────┬────────────────┘
                 │ HTTP /api/*
        ┌────────┴────────────────┐
        │                         │
┌───────▼────────┐      ┌─────────▼─────────┐
│ 聊天后端（我）  │      │ 注册后端（你）     │
│ 老人/情绪/预警  │      │ 账号注册 / 登录    │
└───────┬────────┘      └─────────┬─────────┘
        │  这两个进程互不通信，      │
        │  只通过数据库交换数据      │
        └───────────┬─────────────┘
                    ▼
        ┌───────────────────────────┐
        │  Supabase PostgreSQL 云库  │
        │  "user" / elder_binding …  │
        └───────────────────────────┘
```

**关键点**：两个后端不需要互相调用，各自连同一个库即可。所以：
- 表结构必须双方约定一致（见注意事项文档）
- 谁都不许单方面改表结构
- 数据要"双方都能看到"，唯一的办法就是**都连云库，别连本地文件**
